# Auto-message tracking links

Use exactly one unique URL in the automatic message for each Facebook/Instagram account.

Tracking convention:

- `utm_source`: `instagram` or `facebook`
- `utm_medium`: `dm`
- `utm_campaign`: `auto_message`
- `utm_content`: exact partner-account key

## Expected admin result

Example:

`Instagram -> Vietnam Foodie`

or:

`Facebook -> Vietnammoment`

The customer does not need to come from a bio link. The same tracking works from an automatic DM, story, post, button, Messenger, or any other placement as long as the customer opens the unique URL above before submitting the form.

Important: do not reuse one plain `/journey` link for all accounts. A plain link has no account identifier, so the site cannot reliably know which account sent the customer.
